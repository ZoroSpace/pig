**本批新增偏差与决策**（详见各文件头）：

1. **graph 模型 null 语义落位**：`Edge.Label *string`（nil=null；空串是合法标签——`A[]` 的行为依赖此区分）；`NodeIndex(id, label *string, shape)` nil=不覆盖/缺省用 id，非 nil（含空串）覆盖；`Group.Parent`/`CurGroup`/`NodeGroup` 用 -1 哨兵（内部模型，不上线格式）。
2. **union 落位**：NodeExtra 三型 → 单 struct + Kind（"plain"/"frame"/"compartments"）；SeqItem → interface + SeqMessage/SeqNote/SeqDivider 三具体类型；NoteAnchor → 单 struct + Kind（From/To 与 At 并存）。
3. **字符宽度**：pi 的 Intl.Segmenter（UAX #29）→ rivo/uniseg `FirstGraphemeClusterInString`；宽度表用 pi 自带的 unicode-width 数据（width_data_generated.go）而非 uniseg 的宽度函数，保证与 pi 逐码点一致。孤代理（无效 UTF-8）→ U+FFFD，文件头声明。
4. **JS/Go 语义差**（均文件头声明）：`/\s/`、`split(/\s+/)` 用显式 JS 白名单正则（jsWhitespaceRe/isJSWhitespaceRune，含 \ufeff）；`.trim()` 族 ↔ unicode.IsSpace 系（差 U+0085/\ufeff，无害）；`\p{Alphabetic}` 无 Go 等价 → Letter|Number；Go regexp 不接受原始高位字节与 `\u` 转义 → 控制符正则用 `\x{...}` 形式。
5. **`isAlphanumeric` 单 rune 语义**：TS 正则测的是子串首个 rune，Go 实现同构（多 rune 串只看首 rune）。
6. **displayGenerics 收敛**：pi 在 parse.ts 与 layout.ts 各有一份；pig 落 parse.go 一份、layout 复用（逻辑逐字相同）。
7. **tui/marked.go +MarkedLex**（pig 添加）：mermaid.ts 用 `new Marked().lexer()`（npm marked 原版，无 latex 扩展），pig 的 markedLex 未导出且 markdown 组件带 latex 扩展，故加导出包装（Extensions=nil）。
8. **MermaidTheme 接口**（pig 添加）：pi 直接传 Theme 对象，测试里用 stub 对象；Go 需接口才能 stub，`*theme.Theme` 天然满足（ThemeColor 是 string 别名）。options.Theme 是 `func() MermaidTheme`——惰性解析 theme.Current()，循 T5b-3 决策 11（pi 是活绑定，pig 全局可被 SetTheme 替换）。
9. **SourceBox 签名**：pi 的 `maxWidth?` 可选参 → `maxWidth *int`（lo.ToPtr 构造）。
10. **排序稳定性**：TS sort 在 V8 稳定 → 全部 `sort.SliceStable`；`Math.round` → `math.Floor(x+0.5)`（JS 半数向 +∞）。
11. **移植过程实证修复的两个笔误**（golden 抓出）：readShape 的 closer 匹配误写了 `i+1 < len(chars)`，使 `B[Done]` 的结尾 `]` 永不匹配（must be `i+len(closer) <= len(chars)`）；parseStatement 非 reversed 分支端点写反（from/to 互换）。
12. **transformer 的 join 语义**（mermaid_test 抓出）：pi 是 `lines.map(codeSpan).join("  \n") + "\n"`（分隔符只在行间），初版误写成每行后都补 `  \n`，多出空行。

## 三、风险与坑

1. **marked 的 space-merge 语义**（本批实证发现）：npm marked 的 blockTokens 里，紧跟上一个 token 的**单个** `\n` 会被合并进前一个 token 的 raw（`o.raw += "\n"`），pig 的 marked.go 已实现同样逻辑——T6b 的 session-selector 若再碰 marked 输出边界，注意 raw 里这个"隐形换行"。
2. **selector 族都挂 tui.SelectList/输入组件**：构造期同样不能调 theme.Current()（T5b-3 冒烟坑 11），样式闭包惰性取。
3. **tree-selector（1427 行）是最大单件**，在 T6-2，含会话树渲染/分支预览，测试 4 套——若 T6-2 体量爆表，可把它再单拆，届时更新 handoff。
4. **config-selector 归 P7**：它不被 interactive-mode 引用，消费方是 package-manager-cli/cli 入口，勿提前搬进 T6-1/T6-2（易踩错归组）。
5. -race：新组件被 TUI goroutine 触碰的，参照 interactive_mode_extension_ui_test.go 的 mutex 做法。
6. tmux 冒烟沿用本批的 /tmp/pig_t5b4（mock_server.py 支持任意回复文本，改 REPLY 常量即可）；**严禁 kill-server**；会话名专属（pigsmoke_mmd 已用）。
