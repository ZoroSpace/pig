## 1. 交付明细

### 1.1 共享回调服务器 `ai/auth/oauth_callback_server.go`（pi callback-server.ts 1:1）
- `StartOAuthCallbackServer[T]` 泛型：ProviderName/Host/Port(0=临时)/Path/RedirectHost/State/Complete/Ctx(pi: signal)/Timeout(pi: timeoutMs)； Complete 在回浏览器页**之前**执行（页可显示交换失败，成功 200/失败 502）；404 路由/400 state/409 已处理/400 error param/400 缺 code 分支逐字对齐；redirectURI 从 listener.Addr() 取实际端口（支持 Port 0），IPv6 加方括号。
- `OAuthCallbackOutcome[T]{Value,Err,Cancelled}` channel（pi: promise 的 undefined⇔Cancelled 编码）+ `Wait()`/`Cancel()`（claimed 则不取消——已被认领的回调继续完成）/`Close()`（finish 错误 + **先关裸 listener 再 Server.Close**，2026-09-12 端口泄漏 fix 语义内建；Go `http.Server.Close` 本就丢弃 spare keep-alive 连接，pi chatgpt 的 `closeAllConnections` 隐患在 Go 结构性不存在，文件头注释声明）。
- `WaitForCallbackOrManualInput[T]`（pi 同名）：manual prompt goroutine 与 callback outcome 竞争；已浮出的 manual 错误优先（pi manualError 检查时点）；cancel 后回落 manual。pig 无 per-prompt abort 的既有声明偏差延续（prompt 迟到结果被忽略）。

### 1.2 四家迁移
- **anthropic**（`oauth_anthropic.go`）：删自研 `anthropicCallbackServer`（~110 行），改走共享服务器（state=PKCE verifier，53692）+ `WaitForCallbackOrManualInput`。**顺带修正一处 pig 偏差**：listen 失败原样报错 → pi 语义 `.catch(() => undefined)` 降级 manual-only；成功页文案对齐 pi（"Signed in to Anthropic. You may now close this page."，原为自造文案）。
- **openai-codex**（`oauth_openai_codex.go`）：删自研 `codexOAuthServer`（~110 行），改走共享服务器（1455，state 校验，listen 失败降级 manual——与 pi 一致）+ `WaitForCallbackOrManualInput`；删 pig 手写的 abort-watch goroutine 与 select 竞争舞步（共享层内建）。
- **openrouter**（`oauth_openrouter.go` 新建，pi openrouter.ts 1:1）：**补齐 pig 挂账缺口**（provider 注释自 Phase 2 起 awaiting OAuth flows batch）。PKCE + 临时端口 + 随机 UUID 路径（无 state）+ 5min 超时 + complete=交换内联（30s token 超时）；code 换永久 key（`Expires=MaxInt64`、refresh 原样返回）；listen 失败**传播**（pi 不 catch，临时端口失败即异常）；`OpenRouterProvider.Auth.OAuth` 接线（loginLabel "Sign in with OpenRouter"）。
- **radius** 不迁：pig 无 radius provider（pi.dev runtime overlay，S10-1 已声明），`createRadiusOAuth` 无消费者，不迁死代码。

### 1.3 ChatGPT 登录 `ai/auth/oauth_openai_chatgpt.go`（pi openai-chatgpt.ts 1:1，310 行）
- **动态客户端注册**：固定 `dynamic_agent_client` 授权 → 回调带回 OpenAI 签发的 `client_id`（缺签发即拒），存 `OAuthCredential.Extra["clientId"]`/`["scopes"]`（auth.json 线格式与 pi 同键）；scope 必含 `chatgpt.tokens.use.direct`（缺即拒）；token 响应要求 id_token 存在（仅存在性契约，不解析）。
- **deviceId**：`LoginOptions.GetDeviceId`（pi LoginOptions 1:1，见 1.4）→ `urn:uuid:<uuid>`（大小写不敏感校验 + 小写化）；缺失/非 UUID 在开流**之前**拒绝（不发 auth_url）。`agent_name_hint` 恒 "Pi"（协议值，TUI-LOGO 政策）。
- **自带回调服务器**（pi 1:1 不并入共享层——需从回调 query 取签发 client_id 且页面文案不同）：1455 `/auth/callback`，error param 即拒（"ChatGPT authorization failed: …"），解析失败 400 继续等，成功页 "ChatGPT authentication completed."；listen 失败 notify info 降级 manual；close 关裸 listener（spare 连接隐患同 1.1 声明）。1455 与 codex 共端口：两者是不同 provider 的登录流，同进程先后复用由端口泄漏 fix 保证。
- token 交换/刷新走 form POST（`chatGPTOAuthDo` seam）；expires = now + expires_in − 3min（pi EXPIRY_MARGIN）；refresh 必须轮换 refresh_token（响应缺 refresh_token 即拒）。

### 1.4 LoginOptions 贯穿
- `ai/auth/types.go`：`LoginOptions{GetDeviceId func() string}`；`OAuthAuth.Login` 签名 `(ctx, interaction, options *LoginOptions)`（pi `login(interaction, options?)` 同构）——6 家存量 OAuth 实现 + `composedOAuthAuth`（透传）+ `adaptedExtensionOAuth`（扩展流无 options 概念，忽略）机械适配。
- `ai/models.go` `Models.Login` + `codingagent/core/model_runtime.go` `Login` 增 options 参数逐层透传（pi models.ts/model-runtime.ts 同步）；`interactive_mode.go loginProvider` 传 `&auth.LoginOptions{GetDeviceId: settingsManager.GetOrCreateDeviceId}`（pi interactive-mode.ts:6174 同构）。

### 1.5 settings deviceId（pi settings-manager.ts getOrCreateDeviceId）
- `core/settings_manager.go` `GetOrCreateDeviceId()`：全局层（忽略项目层——防止提交的 project settings 给每个 clone 同一 ID）、首次生成 UUIDv4（复用包内 randomUUID）、`markModified("deviceId")` + save，falsy（空串）重建（pi `!deviceId` 语义）。

### 1.6 pi 的 openai provider OAuth 接线
- pi v0.87.1 的 openai provider 无 OAuth，v0.99.1 换上 ChatGPT 订阅流——pig `OpenAIProvider` 增 `OAuth: auth.OpenAIChatGPTOAuth{}`（Name "OpenAI (ChatGPT subscription)"、loginLabel "Sign in with ChatGPT"、isSubscription）。pig 无 lazyOAuth（Go 静态链接），直接挂值类型，声明偏差。

## 3. 声明偏差
- **radius OAuth 不迁**：pig 无 radius provider，`createRadiusOAuth(options)` 工厂无消费者；等 radius provider 立项时随批。
- **pig 无 lazyOAuth**：pi 用动态 import 把 node:http 代码挡在 bundle 外；Go 静态链接无此关切，provider 直接挂 OAuth 值。
- **url.Values 排序 vs URLSearchParams 插入序**：codex 先例延续，server 不依赖表单序。
- **pig 无 per-prompt abort**：`WaitForCallbackOrManualInput` 内 prompt 迟到返回被忽略（anthropic/codex 既有声明偏差，现集中在共享层声明）。
- **S10-2 抓出的 S10-1 缺口**（openrouter 混型 provider 装配）已在本批修复并记录（§0）。
- **测试基建偏差**：pi 两条测试断言 prompt signal 被 abort（`manualSignal?.aborted`）——pig 无 per-prompt signal，改为验证「callback 胜出且迟到 paste 被忽略」的等价行为。
