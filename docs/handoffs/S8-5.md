## 2. 偏差与决策(均已落代码注释)

1. **FindExtensionStackMatches 收 `[]*Extension`**:pi 的 `Pick<Extension,…>` 窄类型在 Go 无结构等价物;取全类型,多余字段忽略(注释声明)。
2. **crash stack 载体**:pi 读 `error.stack`;Go error 无栈,`getCrashExtensionHint` 走可选 `interface{ StackTrace() string }`(pkg/errors 惯例),普通 error → "" → 无匹配(pi 非 Error → undefined 同语义)。pig 的扩展加载面恒空(Phase 7 不做),生产路径 hint 不会触发,移植价值在纯函数与结构位。
3. **jsDecodeURI 精确移植**:decodeURI 语义(reserved 集不解码、多字节整段校验、ASCII 转义逐个处理)手工实现;测试覆盖 %20 场景,与 pi 5 用例对齐。
4. **entriesRenderedByBoundaryCompaction 惰性分配**:pi 是字段初始化器;pig 构造器初始化之外,handler 内再惰性分配,使 `newSeamTestMode` 等直构路径(绕过 NewInteractiveMode)行为一致(nil map 赋值 panic 是本批测试当场抓的)。
5. **addMessageToChat 双形态修复**(bug,非偏差):登记 `docs/fix/2026-09-22-addmessagetochat-value-form-drop.md`,AGENTS.md fix 列表已补行。
6. **ContextEditEntry 缺 replacement 键**:解码为 nil → "omit",pi 的 undefined → "replace";仅手编 JSONL 才会产生该输入(pi writer 恒写键),case 注释已声明,不为它加自定义 UnmarshalJSON。
7. **无 TTY 冒烟(声明跳过)**:boundary compaction entry_appended 路径仅由扩展 boundary drafts 触发(Phase 7 不做),crash hint 依赖非空扩展列表(恒空);handler 逻辑由 pig-only seam 测试全量驱动,模板为字节级 sync + 金丝雀。
