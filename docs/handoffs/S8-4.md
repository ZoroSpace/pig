## 3. 偏差与决策（本批新增，已落代码注释）

1. **WeakMap/WeakSet → JSON-digest map**（`agentMessageIdentityKey`）：pig 消息是值，对象身份无等价物；JSON sha256 顺带统一值/指针双形态（09-11 fix 教训）。代价：DeepEqual-equal 的两条同内容消息不可区分（后果良性，回退扫描取最新）。
2. **EmitBoundary 初始 buildContext 错误 → panic**：pi 是 promise rejection 使 run 失败；pig 经 agent-loop recover 转成 run failure 事件序列（S8-1 语义）。per-handler 的 build 失败不 panic（=pi 的 catch+emitError）。
3. **in-place edit 检测**：DeepEqual vs 快照（pi 对象身份靠共享引用泄漏 property mutation，值语义无此通道——pig 把元素级差异都视为编辑，已在 EmitContext 注释声明）。
4. **image limits 消费侧**：`normalizePromptImages` 已移植（失败图→hints），但 resizeOptions 源 `model.inputLimits.images.resize` **恒 nil**，等 S8-6 的 Model.InputLimits 落地（agent_session.go normalizePromptImages 注释已声明）；`installAgentToolHooks` 里 normalizeToolResultImages 的 resizeOptions 透传同样留给 S8-6。
5. **restoreToolsFromTranscript 保持 BuildSessionContext()**（pi v0.87.0 同样未改它——勿「顺手」投影化）。
6. `AgentContext.Tools` 转换收拢为 `agentToolsAsPointers`（installAgentNextTurnRefresh 内联段同步替换，行为不变）。
