## 与 pi 的偏差与决策（本批新增）

1. **SDK 承载传输，seam 镜像 JS mock 形态**：pi 靠 `@aws-sdk/client-bedrock-runtime`；pig 的 `bedrockNewClient(ctx, params)` 包级 var = pi 的 vi.mock 等价物（测试捕获 `bedrockClientConfig` 逐字段对齐 pi 的 BedrockRuntimeClientConfig：profile/region/endpoint/credentials/token/authSchemePreference + proxy/force-http1）。事件经 `brtypes.ConverseStreamOutput` 联合体解码（Go SDK 把 mid-stream 异常从联合体成员挪到 `stream.Err()`，pig 的 Next 归一为 error——适配层语义与 pi 的 throw 分支一致）。
2. **catalog golden 重同步至 live**（C2「接受上游漂移」先例）：pi data 冻结于 09-05（121 模型），live 09-15 为 155（新增 gpt-6-astra/grok-4.6/nova 区域 profile 等 42 个、退役 deepseek-r1/gemma-3 等 4 个）；117 个共同模型逐字段比对，57 处差异**全部**为 models.dev 元数据漂移（名称/上下文/价格/推理标志/structured_output→compat），零处理逻辑差异。cost 走 modelsDevCostOf（含 tiers）= P2-T1 既有 pig-wide 决策，pi 现行脚本的 bedrock 块为四字段 inline 形态（不带 tiers）——沿 P2-T1 记录的偏差，非本批新开。
3. **profile-beats-env-keys 的 Go 实现边界**（pi #6957 语义）：JS SDK 配置 profile 时 profile 凭证压过 ambient env keys；Go SDK 链反之。pig 在 profile 配置且无显式 credentials 时用 `LoadSharedConfigProfile` 强制共享配置解析——**仅覆盖静态 key profile**；role/SSO/process profile 回落 SDK 默认链（env keys 可能压过）——声明偏差，pig 不重实现 SDK 全套共享配置凭证解析器。真机验证时按 verify-matrix 行核对。
4. **formatBedrockError 恒走 message 路**：Go SDK 把 HTTP body 折进 APIError message（不保留 $response.body），pi 的 `status: body` 分支（网关 403 场景）无对应物；核心消息取 smithy APIError 的 ErrorMessage（与 JS 异常 message 同源）。
5. **AWS_BEDROCK_FORCE_HTTP1 no-op**：Go SDK 默认 HTTP/1.1（pi 强制 NodeHttpHandler 因 JS SDK 3.798.0 转 HTTP/2）。flag 接受、置位、注释声明。
6. **错误码提取走 `smithy.APIError.ErrorCode()` + `endsWith("Exception")` 门**：modeled 判定 = 非 `*smithy.GenericAPIError`（对应 pi 的 instanceof BedrockRuntimeServiceException 前缀路）；JS mid-stream「裸对象字面量」异常（无 code 可报）在 Go SDK 无对应物（mid-stream modeled 异常都有 code），测试以无 metadata 的普通 error 镜像 pi 断言、偏差入注释。
7. **node-http-proxy.ts 随本批落地**（S3 曾声明不补，属「等消费方出现」状态）：纯 env 解析无 Node 专属 API；bedrock 传 proxy URL 给 Go transport（http/https 目标统一 CONNECT），codex-responses 的消费缺口仍空置（其 S3 记录不变）。
8. **browser 分支无对应物**：pi 的非 Node 环境回落 us-east-1 分支在 pig 不可达（Go 无浏览器形态）。
9. **transport e2e 的 bearer-over-HTTP**：AWS SDK 拒绝在明文 HTTP 上发 bearer token（`bearer token with HTTP request requires HTTPS`），e2e 改走 skipAuth dummy SigV4（与 pi response-headers e2e 同路）；bearer 真机语义留 verify-matrix。
