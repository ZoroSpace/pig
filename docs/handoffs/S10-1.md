### 1.2 生成器合并（步骤 2）

## 2. 批内发现并修复的问题
1. **JS falsy 语义缺口**：OpenRouter decision listing 个别模型 `top_provider.context_length` 为 0，Go 指针判空复刻 JS `||` 会取 0；pi 语义回落 4096（对照发现，已修并加注释）。
2. **cloudflare classifier baseUrl**：pig 复用带 `/v1` 的 `CloudflareWorkersAIBaseURL`，pi 的 REST base 不带（对照发现，已修）。
3. **13MB 编译产物入库**：`ai/scripts/generatemodels/generatemodels` 二进制被误提交，本批移除（建议后续加 .gitignore）。

## 3. 声明偏差（延续 + 新增）
- **classify() 运行时不迁**（Models.classify、ProviderClassifier、system-one-shared/cloudflare/llama-cpp 四 API 实现及其测试）——随 codemode 裁决；typesafe provider inert。
- **generateImages() 运行时延后**：pig 零消费者（pi 也已删 openrouter-images adapter），契约类型保留；有消费者时随 images 链立项。
- **catalog 零值字段**：image/classifier 条目经 pig struct marshal 会带 `reasoning:false`/`maxTokens:0`（chat 形态不变），仅线格式多余键，语义等价；golden 测试已剔除比对。
- **grok-build-0.1 responses-compat inert 键丢弃**：S7 已声明，对照中唯一 chat diff，维持。
- **mistral（32 chat）/radius（28 chat）静态 catalog 不镜像**：既有缺口（mistral adapter 未移植、radius 为 pi.dev runtime overlay），pig 侧 radius 走 runtime 通路；不在本批范围。
- **pi.dev 协议脚本本体**（index/revision 选择）不迁，客户端半区已锁（见 1.4）。
