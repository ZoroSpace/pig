### 10. 27c7b6ff4 — bash ANSI 跨 chunk strip

**pi diff 摘要**（bash-executor.ts +92/-61 重构 + ansi.ts +46）：
- `utils/ansi.ts`：`ansiRegex()` 函数提为模块级 compiled regex（`(?:OSC_START[\s\S]*?ST)|CSI_START+CSI_FINAL` g）；新增 `splitIncompleteAnsiSuffix(value)` → `{complete, pending}`——无 `\u001B`/`\u009B` 短路全量放行；否则只在尾部 `MAX_PENDING_ANSI_LENGTH=256` 字节窗口跑 `unfinishedAnsiAtEndRegex`（OSC 未闭合（允许尾部裸 ESC 非 `ESC\`）或 CSI 无 final byte）匹配 `$`，命中则按 match.index 切
- `bash-executor.ts`：onData 改 `pendingAnsi + decoder.decode(data,{stream:true})` → split → `appendText(complete)`（appendText = 原 sanitize/strip/\r 归一 + tempFile + chunks + OnChunk 管线，空文本早退）；新增 `flushOutput()` = `pendingAnsi + decoder.decode()`（无参尾包）→ appendText；try/catch 重构为单出口：exec 成功或 abort 都走 flushOutput + 统一组 BashResult（cancel 时 exitCode undefined），非 abort 的 exec 异常 tempFile.end 后 rethrow

**pig 落点**：
- `codingagent/utils/ansi.go`：补 `SplitIncompleteAnsiSuffix(value string) (complete, pending string)`——ST/OSC_START/CSI_START/CSI_FINAL 常量 + 尾窗口正则（Go regexp 无 look-ahead，`(?:...|\u001B(?!\\))*` 需改写为等价交替；验证用例覆盖尾部裸 ESC）；`StripAnsi` 本体 regex 语义与 pi 新 compiled 版对齐核对（现实现是等价手写还是 regex，开工先读）
- `codingagent/core/bash_executor.go`：`:55-62` bashExecutorDecoder（自定义 UTF-8 chunk 保留）——**先确认有无 flush 出口**（pi 无参 decode），无则补 `flush()`；`:124-129` onData 改 pendingAnsi 缓冲（split 在 decoder 产出字符串之后）；`:167-204` abort 路与正常路**都必须走 flushOutput** 再组结果（abort 时 flush 的残段也要进 tempFile/chunks/OnChunk）
- **测试**：pi `test/suite/agent-session-bash-persistence.test.ts` +59 行（跨 chunk ANSI 用例，SGR 序列切在 chunk 边界、长序列 >256 放行、尾部裸 ESC）→ pig bash_executor 测试补同族例（现有 bash_executor 测试文件开工时定位，persistence 语义 pig 有对应物）
