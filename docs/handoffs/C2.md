## 关键决策与偏差

1. **fake timers → 双 seam**：`deviceCodeNow`+`deviceCodeSleep`（device_code.go 泛型层），测试的 `oauthFakeClock` 同时接管两者（注册即 signal 保证无竞态）；pi 的 `advanceTimersByTimeAsync` 语义由 `advance(d)` 按已登记 duration 推进复现（含 4999/1ms 精度断言）。
2. **device interval 语义**：struct 保 float64 解析保真（"5.5"、"" → 0 等 JS Number 怪癖），过 PollOptions 边界才 floor 成秒（pi 在秒→ms 时 floor；实际 interval 全整数，声明偏差）。
3. **browser 路手动 prompt 竞速**：pig 无 per-prompt abort，manual 结果晚于回调则忽略（anthropic 先例）；`await manualPromise` 兜底分支等价 `<-manualCh`（与 pi 同为"prompt 不 settle 则不返回"）。
4. **form/auth URL 编码**：`url.Values.Encode()` 键序排序 vs pi URLSearchParams 插入序——服务端不依赖，xai/anthropic 先例。
5. **models.json 顶层必须有 `providers` 键**（冒烟时实证：缺顶层键整个文件被 schema 拒、LoadError 静默容忍回落 builtin——与 pi schema 一致，非 bug）。
6. **本批环境坑（勿再踩）**：本沙箱 outbound 443 被黑洞（SYN 挂死）——codex 请求打到真 chatgpt.com 会无限挂；CLI 冒烟必须本地 mock + models.json 覆盖。且 codex SSE 请求体是 zstd 压缩，naive mock 会 UnicodeDecodeError，用 klauspost/compress 解。
