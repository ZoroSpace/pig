## 1. tui 叶子层（色彩引擎 + 终端色彩查询）

### 1.1 `tui/oklab.go`（新，pi oklab.ts 1:1）
Ottosson OKLab/OKHSL 参考实现（MIT 头注保留）：四矩阵常量、saturation fit 半平面+系数表、`OklabToOkhslLightness`/`okhslToOklabLightness`、sRGB 传递函数、`OklabToLinearSrgb`/`RgbToOklab`/`LinearSrgbToRgb`、`maxSaturation`（Halley 一步）、`cusp`、`maxChroma`（上半三角边+逐通道 Halley，`u<0` 步取 MaxFloat64 哨兵）、`chromaStops`（c0/cMid/cMax）、`OkhslToRgb`/`RgbToOkhsl`（0.8 分段 + 饱和度 clamp）。

### 1.2 `tui/colors.go`（新，pi colors.ts 1:1）
- `Color` 结构体三型（`ColorKindIndexed/Rgb/Oklch`；pi 的 discriminated union 收敛为 struct+kind，调用面更 Go）；构造器 `NewIndexedColor/NewRgbColor/NewOklchColor/NewOkhslColor`（错误文案逐字）。
- `ParseColor(value any)`：int/float64 → indexed；`#rgb/#rrggbb`、`oklch(L C H)`（L 支持 `%`、H 支持 `deg`）、`okhsl(H S L)`（S/L 支持 `%`）——正则逐字对齐 pi 的 NUMBER_PATTERN。
- `ColorToRgb`（indexed 查表 / oklch 色域二分 20 步、hue 固定、无色度兜底）、`ColorToOklch`/`ColorToOkhsl`/`ColorToHex`、`MixColors`（oklch 默认 + srgb；无彩 hue 继承规则 1e-7）。
- `rgbToAnsi256`（cube/gray 竞争 + spread<10 判据）、`ForegroundAnsi/BackgroundAnsi`、`StyleText/StyleTextWithAnsi`（reset 反序拼接逐字）。
- `TerminalColorMode`/`ColorMixSpace` 类型常量（`ColorMode256color`/`ColorModeTruecolorN`——后缀 N 避免与 theme 包旧常量名冲突的别名链）。

### 1.3 `tui/terminal_colors.go` 重写（pi terminal-colors.ts v0.99.1）
`TerminalColors{Foreground,Background *RgbColor, Palette []RgbColor}`（palette 仅在 16 色全到齐时非 nil）、`OscColorTarget`（fg/bg/palette index 三型 + `key()` 去重键）、`ParseOscColorResponse`（OSC 10/11/4 统一解析，`#` 6/12 hex 与 `rgb:`/`rgba:` 4 位/通道格式保留）；`ParseTerminalColorSchemeReport` 不变。**删除** `ParseOsc11BackgroundColor`/`IsOsc11BackgroundColorResponse`（pi 同步删除；唯一消费者 tui.go 同步迁移）。

### 1.4 `tui/tui.go` 查询面重构
- **新查询** `QueryTerminalColors(timeoutMs int, onLateReply func(TerminalColors)) TerminalColors`：OSC 10+11+4×16 一次突发 + 尾随 DA1（`\x1b[c`）标记回复结束；DA1 回复或 18 项全到齐即完成，超时返回已收子集且**后续迟到回复经 onLateReply 继续送达**（pi: promise + onLateReply）。
- **并发模型**（pig 独有，延续 2026-09-19 死锁 fix 契约）：每查询自带 `q.mu` + CAS settled，b.mu 只护队列切片；timeout goroutine 与 input-dispatch 消费路径在 q.mu 上竞争 settle，先者解阻塞调用者、后者（超时后完成）调 onLateReply（回调内**清空 deliverLate**，一次完成只投递一次——pi 的 `deliver=undefined` 语义）。`QueryTerminalColors` 完成后将自身移出队列（pig 添加：队列按位 shift 的 pi 语义在「先完成后 DA1」时序下会漏移位）。
- **删除** `QueryTerminalBackgroundColor`/`QueryTerminalColorScheme`（996 DSR 查询路）及 pendingOsc11 机器；TUI 接口面同步收窄为 `QueryTerminalColors`。`tui/terminal_query_deadlock_test.go` 重写为对 QueryTerminalColors 的同型回归（dispatch 持锁超时 settle + 真回复胜超时，OSC11 回复 + DA1 触发）。

## 2. theme 包重构

## 4. 声明偏差汇总

1. **Color union → struct+kind**：pi 三 interface union，pig 单 struct + `ColorKind`；`parseColor(string|number)` → `ParseColor(any)`。构造器校验错误文案逐字保留。
2. **查询面阻塞化**：pig `QueryTerminalColors` 阻塞返回 + onLateReply 补偿（延续 pig 阻塞查询既有偏差族）；controller 灰度窗口时点差异见 §2.3。队列移除策略 pig 按「查询自身完成即移位」实现（pi 移位仅在 DA1；两者在 18 项全到齐后迟到 DA1 的处理等价——后续回复被 replied 集吞掉）。
3. **ThemedText 不单独成组件**：pi 新建 ThemedText 并转换 ~50 个调用点；pig 以 `expandableText.Invalidate()` 闭包重建等价覆盖 **header/notices 家族**（header 构造已移入闭包），其余散点 baked-string 站点维持原状（下次触碰时再转，行为差距仅限「切换主题后这些行不重着色」——与 v0.87.1 相同，无回归）。
4. **内置主题 pig 调色微调废止**：2026-09-24 用户指定的 light.json `syntaxVariable/syntaxKeyword` hex 覆盖随 pi 全新 OKHSL 色板 redesign 失去对象（旧 palette 整体重设计），本批按 pi v0.99.1 主题逐字节采用；新 light 主题下 syntaxVariable=okhsl(203 73% 46%)、syntaxKeyword=blue 族，**请 dogfooding 复验亮色主题可读性，不满意再单独调**。
5. **小数 wheel 固定值**：pi `WheelScrollLines` 可为 0.5 等小数，pig settings 层 clamp 整数（无消费者）；`setLines(0.5)` 测试断言改为 `SetLines(1)`。
6. **#9973/#9957 跳过**：消费面在 pig 未移植的半区（见 §3）。
7. **brightness golden 放宽**：无彩色（C<1e-7）的 hue 分量不比（浮点噪声），L/C 仍 1e-9 全量比。
