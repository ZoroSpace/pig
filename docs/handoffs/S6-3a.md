## 3. 风险与坑（本批实证）

- **runAgentPrompt defer 内持锁调 finishCancelledRetry 自死锁**（已修：锁内读标志、锁外调方法）——任何在 s.mu 临界区内调会再取 s.mu 的方法都是同型雷。
- **EstimateTokens/SessionEntryToContextMessages 只认值形态消息**（指针形态走 default→0 tokens）——新测试 fixture 一律用值形态（`types.AssistantMessage{...}` 非 `&`）。
- `types.Model` 无 ProviderName 字段；Provider 是 `types.ProviderID` 要显式转换。
- settings 数值校验是 pi isSafeInteger 语义（`math.IsNaN/IsInf/Trunc/9007199254740991`），错误文案经 `formatSettingValue` 逐字对齐 JS String()（空数组→""、NaN→"NaN"）——测试断言逐字比对的改动必须走它。
- pi 测试文件非 ASCII 字面量先 hexdump 核对（S6-2 教训，clipboard/skill 相关测试仍可能踩）。
- `createAgentTestSession` 默认 seed SystemPrompt "Test" 且默认 StreamFn 是真实 defaultStreamFn（会真连网）——新 e2e 必须 `OmitSeedSystemPrompt: true` + 显式 mock StreamFn。
- FindCutPoint #9740 后 fallback 是 cutPoints[last]（不再是 cutPoints[0]）——断言别抄旧期望。
- 会话 listing 并发已重排（mapWithConcurrency + partial progress）；interactive session-selector 的 partial 消费在 3b，别提前改 selector 行为。
- 所有阻塞命令套 timeout；`go test` 带 `-timeout`；全量 -race 只跑一次存变量。
