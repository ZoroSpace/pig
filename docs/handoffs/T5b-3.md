**本批新增偏差与决策**（详见各文件头）：

1. **工厂签名去掉 theme 参数**：pi 的 setWidget/setFooter/setHeader/custom/editor 工厂第二参是 Theme；core 包不能 import modes/interactive/theme，且 pig 组件自 T5a-1 起统一读 `theme.Current()` 全局——工厂只收 tui（footer 另收 ReadonlyFooterDataProvider）。
2. **setWidget 双 overload 合一**：`content any`（nil 删除 / []string / ExtensionWidgetFactory），注释声明接受类型。
3. **custom<T> → `Custom(ctx, factory, options) any`**：阻塞至 done 回调（与 Select/Confirm/Input 一致），类型安全留在扩展侧闭包（Go 接口方法不能泛型）。
4. **TerminalInputHandler 修正**：T5b-2 的占位是 `func(data string)`，丢了 pi 的 `{consume?, data?}` 返回——本批改为 `func(data string) *TerminalInputResult`（消费/改写语义）。
5. **新增 `TuiBase.RunExclusive`（pig 添加）**：pig 无单事件循环，扩展对话框从 handler goroutine 变更组件树会与渲染管线竞态（-race 实测抓到）。RunExclusive = 复用 TuiBase.lock（goroutine 重入）暴露的互斥面；`InteractiveMode.mutateUI` 包住所有跨 goroutine 的容器变更。**注意：interactive_mode 里 handleEvent/addMessageToChat 等既有路径的容器变更仍是裸的（T5b 以来的存量），如后续 -race 大范围跑交互路径需要同样包 mutateUI。**
6. **m.editor 放宽为 tui.EditorComponent**：AddToHistory/GetExpandedText/InsertTextAtCursor 走 capability 断言（editorAddToHistory 等 3 个 helper）；EditorFactory 返回 EditorComponent，但 OnSubmit/OnChange/borderColor/actionHandlers 接线仅对 `*components.CustomEditor` 生效（pi 鸭子类型的成员都在 CustomEditor 上；其它实现走 capability 接口）。
7. **SetTheme 只收名字**（Theme 实例分支无 core 可表达参数类型，随 theme loader 半区）；GetTheme 返回 any（*theme.Theme）。
8. **getStartupExpansionState 修复**：T5b 存量 stub 恒 false，本批改回 pi 语义 `options.Verbose || toolOutputExpanded`（移植测试抓出）。
9. **checkForPackageUpdates 未移植**（P7 package manager）；createBaseAutocompleteProvider 的 login 用例随 T6（getLoginProviderOptions 未移植）。
10. **测试适配**：pi 的 formatScopeGroups "resource-list" stub 断言（2 例）改为断言真实展开渲染；git 源 compact 标签期望值改为 pig 的退化行为（`git:github.com/...` 全串，parseGitUrl 随 P7 恢复）；showExtensionCustom 测试组件加 mutex（-race，TUI goroutine 触碰）。
11. **fullscreen 冒烟发现的坑**：createInteractiveTui 在构造期调 theme.Current() 会 panic（theme.InitTheme 在 Init 里才跑）——样式闭包改为调用时惰性取主题（pi 的 theme 是活绑定，等价）。
12. SettingsManager.GetHTTPIdleTimeoutMs / ReloadOptions.BeforeSessionStart(ctx) 等既有 pig 签名与 pi 命名有差，接线时按 pig 为准。

## 三、风险与坑

1. **TS 世界的字符串索引**：grok-mermaid 全程 UTF-16 码元索引 + charCodeAt 宽度查表；pig 全仓约定是 rune 世界——canvas/labels/width 三件要统一选一边（建议：内部用 rune + uniseg 宽度表对齐 width-data 的语义），**不要混用**。pi 侧 golden 对照能兜底。
2. **layout-seq（时序图）与 layout（流程图）是两套布局**：先流程图后时序图，别共享状态。
3. **mermaid transformer 挂在 user/assistant markdown 渲染链上**（getMarkdownTransformers），渲染是同步的——大图会卡输入 goroutine，pi 同样如此，不要"顺手"加缓存/异步。
4. interactive 包测试要过 -race：新组件若被 TUI goroutine 触碰，参照本批 testFocusableComponent 的 mutex 做法。
5. tmux 冒烟沿用 /tmp/pig_t5b；**严禁 kill-server**；会话名专属（pigsmoke2 已用）。
