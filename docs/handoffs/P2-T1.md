### 与 pi 的偏差与决策（本批新增）

1. **known-ids hook**：pi 的 oauth 文件静态 import 生成 catalog；pig 分层禁止 auth→ai，改为 `auth.SetGitHubCopilotKnownModelIDs`，providers 包 init() 注入 `ai.MODELS`。auth 侧测试用合成 catalog，真 catalog 集成在 providers 侧测试。
2. **cloudflare-ai-binding.ts 不移植**：Workers 运行时专属（`env.AI.fetch()` 传输），pig 二进制结构不可达（photon 同类声明缺口）。
3. **google golden 重同步**：modelsDevCostOf 补齐 cost.tiers 载运（pi getModelsDevCost 本就保留；此前丢弃被无 tiers 的 golden 掩盖）后，models.dev 于 2026-09-05 后给 google 模型新增的 context tiers 进入 catalog——C2「接受上游漂移」先例，testdata/google.json 按现状重同步（逐字段核对：除 tiers 外零差异；google-vertex 零漂移未动）。
4. **grok-build-0.1 compat**：pi 把 completions-only 的 `supportsReasoningEffort:false` 展进 openai-responses compat（无读者，惰性键）；pig 对 responses 形态保留原样并在注释声明。
5. **verification_uri 规范化**：Go url.Parse 拒绝控制字符而 pi 的 URL 会转义；`escapeControlBytes` 先转义再解析，语义对齐（拒绝恶势 scheme 的行为不变）。
6. **上游漂移接受**（ pig catalog 再生成自 live models.dev，pi data 冻结于 2026-09-05）：opencode-go 价格更新 + glm-5.3-flash 改名、omen-alpha 标 deprecated 被正确跳过、qwen-token-plan-cn 新增 deepseek-v4.1-flash——live 数据与 pig 输出逐字段一致，非移植偏差。
7. **login→store 持久化半区**：pi 的 budget 停止用例断言 Models.login 落盘；pig 拆为 auth 侧（budget 停止行为）+ 泛化凭证同步测试（model-runtime credential-sync 已覆盖 store.Modify 管道），providers 侧测试文件头声明。
