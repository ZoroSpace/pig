## 2. 偏差与决策

1. **offline env 裁决:沿用 `PI_OFFLINE`(无 PIG_ 变体)**——S8-6 handoff 曾倾向 PIG_OFFLINE 回落 PI_OFFLINE,但 pig 全仓已有 8 处裸读 `PI_OFFLINE`(version_check/tools_manager/model_runtime/main.go/interactive_mode 等),引入 PIG_OFFLINE 会成为唯一特例且两名字同时可设时优先级反而制造歧义;pig 对 pi 网络类 env 一贯保留原名(同 PI_SHARE_VIEWER_URL 先例)。已落 bug_report.go 注释。
2. **pi frontmatter 诊断 message 断言适配**:pi 断言 message 含 "line 1, column 14"(npm yaml 位置格式);yaml.v3 该形态的 scanner 错误无位置信息,两测试改 pin "mapping values" 子串,测试注释声明。
3. **mime.ts 半区不单独测**:pig 的 `codingagent/utils/mime.go` 本就委托 `agent/harness/tools.DetectSupportedImageMimeType`(pi 是双拷贝),一份实现一份测试覆盖两处消费面。
4. **tui centered 测试 delay 0→50ms + 箭头字形定位**:pi 的 0ms hide timer 在渲染后触发(微任务/宏任务序),可见帧可观测;pig 真 time.AfterFunc 与渲染 goroutine 并发,0ms 下可见帧不可稳定观测——改 50ms delay 并在 SendInput 后同步断言 IsScrollbarVisible(input 分发同步);pi 用 indexOf(label) 而 pig VirtualTerminal 裁尾随默认属性单元(标签尾空格被裁),改用 "↓" 字形索引 = 标签列+1,注释声明。
5. **spans-transcript 测试为 S4 缺口补移植**:该测试 pi v0.85.1 已存在,pig S4 漏移植;本批随 #9842 新断言一并补齐(旧代码下该测试也绿——全宽标签场景新旧裁剪恰好同形,它不是回归检测器,centered 测试才是)。
6. **pig-only 测试三处**(stat-fail 子测/GIF 反例/offline 拒绝):pi 对应分支无测试或测试锁不住回归,按 pig 回归登记规则补齐。
7. **prompt_templates.go 显式路径双 stat 收敛为单 stat**:pig 旧代码 stat 了两次(历史移植形状),pi 本就一次;新语义下第一跳失败即发诊断,双跳失去意义。
