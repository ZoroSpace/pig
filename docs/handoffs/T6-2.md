1. **model-search.ts 下沉 components**：pi 在 modes/interactive/；pig 的 /model 选择器在 components 包（不能反向 import interactive），故 ModelSearchItem + 两个函数正典化在 components，interactive 侧 model_search.go 再导出（alias + 包装）。

3. **mutator 走构造参数**：SessionSelectorComponent/ModelSelectorComponent 的后台 goroutine（loadScope/refreshModels）在构造时启动，mutator 必须构造期确定，故为尾参 `mutator func(func())` 而非可后设字段（后设会数据竞争）。nil = 内联（测试）。

5. **sessionsLoader 同步形态**：pi async loader → pig `func(onProgress func(loaded,total int)) []core.SessionInfo`，loadScope 内 goroutine 包装 + Mutator 串行化应用。
