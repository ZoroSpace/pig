## 3. 风险与坑（下个 session 必读）

- **SystemSections 保序不变量**：任何触碰 Sections 解码/编码/回放的改动，先想键序——乱序 = 同一 transcript 两次请求渲染不同 prompt = prompt cache 失效
- **defaultStreamFn 必须保持包级单例**（codingagent/core/sdk.go）：AgentSession 身份比较依赖它；不要在调用点内联闭包
- **addedToolNames 线格式删除**：旧 pig 会话 JSONL 里该字段读侧自然忽略；但 pig 的 extensions_wrapper 简化后，扩展运行时新增工具不再经 addedToolNames 通道——extensions 未迁移所以无消费方，S6-3/S6-4 碰 agent-session 工具注册时别把它加回来（pi 已走 system 消息声明路）

- **批量文本处理工具必须有界**（本批 volcengine 事故 + 09-18 autocomplete 事故同源教训）
- pi 的 data/*.json 不在 git 里（gitignored 产物）——做 golden 对比必须真跑 pi 生成器，别 `git show v0.86.0:path` 找
- `ai/utils` 包名是 `utils`（非 aiutils）；`codingagent/core` 里 import ai/utils 用别名 `aiutils`；两处不要抄混
