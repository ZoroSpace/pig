4. `InputOptions.Prompt` 用 `*string`（TS `??` 语义：显式空 prompt 合法，不能与未设置混淆）；NewInput 改 variadic 保持旧调用兼容。

## 3. 风险与坑

- `renderedOverlayLayouts` 复用 `[:0]` 背底：compositeOverlays 与 dispatchMouseToOverlayLocked 必须同锁（均在 b.mu 下）；entry nil 会在 overlay 命中时 panic（本批已踩过一次）。
- `RenderNow(true)` 会 resetRenderState 走全渲染——pi 测试的 `renderNow()` 无参是 `RenderNow(false)`，移植测试时勿带 force。
- `InputOptions.Prompt` 是 `*string`：空字符串是显式值。
- `isPlainContainerMouse` 依赖 reflect 方法指针：若未来有组件 override HandleMouse 同时嵌入 Container，自动正确；但重命名方法会静默破坏。
- VirtualTerminal trim 语义差异（偏差 7）会让依赖尾随空格的 pi 断言在 pig 失败——按 trimmed 形式改写断言并注释。
