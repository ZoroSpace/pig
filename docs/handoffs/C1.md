## 关键决策与偏差

1. **WS 传输以 gorilla/websocket 实现而非再延期**：codex 是 pi 中唯一真正消费 `TransportWebsocket/TransportWebsocketCached` 的 adapter，Phase 1 的"WS 未实现"缺口在本批补齐。pi 的全局 WebSocket 构造器 → pig 包级 `codexDialWebSocket` seam var（tests 覆盖，等价 vi.stubGlobal）。
2. **panic→recover 错误管道**：Go iter.Seq 不能 yield error，codex 的 mapCodexEvents/parseSSE/parseWS 错误（codexApiError/codexProtocolError/abort/idle-timeout）以 panic 传播，`runCodexReduction` 与 WS 的 process 闭包 recover 转 error——与 pig 既有 "pi try/catch → panic+recover" 惯例一致。
3. **header-timeout 只管 headers 阶段**（pi：`combinedSignal.cleanup()` 在 fetch finally）：Go 的 request-ctx 无法 detach，用 `context.WithCancel` + `time.AfterFunc(reqCancel)` 手工等价，成功后 timer.Stop、body 经 `codexCancelBody` 在 Close 时释放 ctx。
4. **pi 怪癖保真**：`connectWebSocket` 的 `delete wsHeaders["OpenAI-Beta"]` 是大小写不匹配 no-op（headersToRecord 输出小写键），WS 握手实际带 openai-beta 头——pig 不删，注释声明；`useCachedContext` 比较的是 RAW options.transport（undefined ≠ "auto"），transport 未设时走 WS 但不启用 delta。
5. **prompt_cache_key 空串省略**（pi undefined 语义）；`end_turn` 仅 boolean 捕获（JSON null → 不写）；`strict: null` 经 `StrictNull` 三态字段表达。
6. **首测试轮暴露并修复 2 个实现 bug**：① `Messages: []types.Message{output}` 传指针而转换器只分发值类型分支 → continuation 的 lastResponseItems 恒空、delta 多发 item——改 `*output`；② body 字面量把空串 prompt_cache_key 写进 JSON——改条件省略。两者均由 pi 测试先行锁定。
7. **测试资产**：`codexOnPayload` 适配 promoted 选项的 `any` 签名；WS mock 的 Read 实现三路 select（ctx/idle/inbox）；TypeBox fixture 需手补 `required`+`additionalProperties:false`（TypeBox Object 默认注入，JSON 手写容易漏）。
8. **openai-responses 的 `decodeResponsesSSE` 合成 parse_error 事件**的 B1 偏差不适用于 codex：pi 的 codex parseSSE 抛 CodexProtocolError，pig 按此语义 panic→error 流终止，errorMessage 为 "Invalid Codex SSE JSON: …"。

## 风险与坑（本批实证，C2 大概率撞）

- **promoted 字段不能进 struct 字面量**：types.StreamOptions 嵌入 ProviderRequestOptions，APIKey/Fetch/OnPayload/TimeoutMs/MaxRetries 等只能构造后赋值（本批测试全部走该模式，照抄即可）。
- **OnPayload 签名是 `func(payload any, model *types.Model) any`**：取 map 需类型断言（`codexOnPayload` helper 在测试文件里）。
- **TS fixture 的 TypeBox 对象默认带 required/additionalProperties:false**；grammar 工具还要求"恰好一个 required string 属性"，JSON 手写缺 required 会报 "requires exactly one required string property"。
- **重试/WS 类测试必须显式 Transport**：不设 → auto → WS 路径 → 未 stub 的 seam 会真实拨号（测试 15s 卡顿的根因）；SSE-only 用例一律 `options.Transport = types.TransportSSE`。
- **非规范化 header 断言**用 `codexReqHeader(reqFromHeader(h), name)`（adapter 按原样大小写直写 http.Header，http.Header.Get 的 canonical 化会 miss）。
- **generatemodels 再生成后**：`ai/models_generated.go` 会整文件重写，注意 all_test 里 BuiltinProviders 数量断言与 catalog accessor 断言同步 +1；models.json 逐字段比对脚本流程照 B2 handoff。
