## 关键决策与偏差

1. **content 快照所有权归 reducer**：与 completions 不同，responses 的 blocks 列表在 `ProcessResponsesStream` 内部，stream 层只 push start/done/error 且**不再 syncContent**（content 由 reducer 每次 push 刷新）；failure 路径 content 即最后一次 push 的快照，scratch 字段（partialJson/customInput）在 Go 值快照里天然不存在。
2. **`data:` 单行驱动**：Responses SSE 的 `event:` 行信息与 data JSON 的 `type` 字段重复，解析器只读 data（与 completions 共用帧格式）。
3. **fixtures 手工镜像 catalog**：B1 时 pig catalog 无 openai 模型，测试 fixture 从 pi `data/*.json` 逐字段抄录；B2 落地后 catalog 为权威（B1 fixture 保留，锁 adapter 语义不锁 catalog）。
4. **mapStopReason 未知状态不 throw**：pi exhaustive switch 的 default 抛错；pig 映射为 stop 保持 reducer total（注释声明，现有状态全覆盖）。
5. **header 大小写**：`createResponse` 用 `req.Header[name] = []string{value}` 直写保持 `session_id` 等原始大小写（行为等价：HTTP header 大小写不敏感，但线字节与 undici 一致）。
