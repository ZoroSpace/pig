## 三、风险与坑（本批实证）

1. **initTheme 在 interactive 包测试会 panic**：必须先装 TestMain（PI_PACKAGE_DIR→`theme/testdata`，路径是 `filepath.Join("theme","testdata")` 不是 `..`）——已建 `testmain_test.go`，后续测试直接用 `initTestTheme(t)`
2. **RE2 无 lookahead/反向断言**：pi 正则逐条核对（本批踩了 LEGACY_REPO_RE 的 `(?=/|$)`）；`\-` 在字符类内也报错，用 `[...-]` 尾置
3. **Go regexp/strings 与 node 语义差**：`path.posix.normalize` 保留尾斜杠、`path.posix.parse` 的 name 无扩展名——getShortPath/getCompactExtensionLabel 已按需适配，改这段时先读测试
4. **FetchWithRetry 默认 MaxRetries=2**：pi 的 version-check 语义是「不传 retry 就不重试」，GetLatestPiRelease 里显式归零了；复用 FetchWithRetry 的新调用点都要查这条
5. **showLoadedResources 内 21 个 helpers 全部只依赖 m.formatDisplayPath/m.sessionManager**——同包测试可构造 `InteractiveMode{}` 部分字段直调，不需要 session seam；先写 helpers 测试再接 showLoadedResources
6. **tui.CombinedAutocompleteProvider 的 SlashCommand.ArgumentHint 是 string 不是 *string**（与 pi 的可选语义有差，T2 定的）——`lo.ToPtr` 包上去会编译错
7. tmux 冒烟沿用 /tmp/pig_t5b（mock_server.py + models.json + auth.json）；**严禁 kill-server**，会话名专属
