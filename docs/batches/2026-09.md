- **process.nextTick → goroutine**：微任务合并次序（同一次同步块内多次输入合并为一帧渲染）在 Go 的 goroutine 调度下不可观测——机制保留（标志位逻辑逐字），测试断言改为“prompt render + 最终输入态”而非精确帧数（文件头声明）；`@xterm/headless` 仿真 → 自写迷你 VT 仿真器（`virtual_terminal_test.go`，仅覆盖 TUI 所发序列子集：光标移动/擦除/自动回绕/滚动回绕/OSC-APC 跳过/SGR italic 等属性跟踪），`waitForRender` = 35ms sleep（16ms 节流 + 调度余量）
- **杂项偏差（均文件头声明）**：Terminal 接口 drainInput Promise → 阻塞方法；ProcessTerminal 的 process.stdin/stdout → 可注入 in/out 字段（测试注入管道替代 pi 的 monkey-patch）；setEncoding('utf8') → readLoop 内增量 UTF-8 解码（跨 chunk 多字节缓冲）；native-modifiers 原生 .node 模块 → IsNativeModifierPressed 恒 false 存根（enableWindowsVTInput 同理 no-op）；`_lastEventType` 在 pi 中只写不读，不移植；Promise 查询（queryTerminalBackgroundColor/queryTerminalColorScheme）→ 阻塞调用（channel + timer 语义等价）；SizeValue（number | "50%"）→ any + parseSizeValue 类型开关；KEY_PAGEUP 等驼峰 keyId 字符串逐字保留（"pageUp"）
- **测试**：keys/stdin-buffer/terminal 测试整体移植（含 Windows Terminal 0x08 分岔、SS3/rxvt 修饰序列、bracketed paste、Kitty 打印去重、协议协商全部分支）；tui-render.test.ts 移植 13 用例，**4 个依赖 Image 组件的用例随 Phase 8 跳过**（文件头声明）；tui 包 39 个测试函数，-race ×3 全绿，全仓 697 个测试函数
